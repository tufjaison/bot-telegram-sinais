# ⚽ Bot Telegram — Analisador de Chutes e Apostas

Bot que recebe a imagem do bilhete, extrai o texto via OCR, busca estatísticas em tempo real da API-Football e retorna a análise completa com as melhores opções de aposta.

## Funcionalidades
- 📸 Envie a foto do bilhete — OCR automático
- 🌐 Dados em tempo real via API-Football
- ⚽ Análise de Chutes e Chutes ao Gol
- 🏠 Ajuste Casa/Fora (+8% / -6%)
- 📊 Cálculo de Edge% e Valor Esperado
- ✅ Recomendação: Tem Valor / Sem Valor
- 📋 Resumo completo de todos os jogos

## Como Usar
1. Inicie o bot com `/start`
2. Envie a foto do bilhete
3. Aguarde a análise (5-15 segundos)
4. Receba o relatório com as melhores apostas
